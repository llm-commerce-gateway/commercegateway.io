## Who hosts Commerce Gateway?

Commerce Gateway is created and maintained by Better Data. The hosted runtime runs on Better Data infrastructure.

## What's included in hosted

- Hosted gateway process (Better Data operates Node)
- Same OSS connectors (Storefront / Woo / BigCommerce)
- Other features (isolation, portal, metering, SSO, SLA) **only if the pilot agreement includes them**

## Open source commitment

The gateway protocol, tool schema, and self-hostable packages are **Apache-2.0** and remain open source. The hosted platform is a commercial service built on top.

Comparable model:

- Nginx (OSS) vs Nginx Plus (commercial)
- Kubernetes (OSS) vs GKE/EKS/AKS (hosted)
- Commerce Gateway (OSS) vs Better Data hosted platform (commercial)
