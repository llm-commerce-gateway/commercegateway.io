## What a hosted pilot can include

Treat the items below as **negotiated**, except the managed Node runtime itself.

### Managed gateway infrastructure

Better Data can run the Commerce Gateway process so the customer does not operate Node. Scope (updates, TLS, monitoring) is per pilot.

### Console, registry, brand portal

Operator UI, public registry listing, and merchant-facing config **may** be part of a given pilot. Do not assume they ship with every environment.

### Usage analytics

**Not a GA claim.** Dashboards and metering may be part of a specific pilot. Do not sell “full usage analytics” as a generally available hosted feature.

### Registry MCP

Your gateway is reachable via the Commerce Registry MCP at `mcp.commercegateway.io` — enabling LLM clients that support MCP to discover and connect to your gateway without manual configuration.

### Enterprise features (targets, not GA)

- Agency hierarchy / delegated admin
- Customer-facing metering and consolidated billing
- Enterprise SSO
- Contractual SLA

Do not put these in a partner SOW unless the pilot agreement lists them.

## Open source commitment

The gateway protocol, tool schema, and self-hostable packages are **Apache-2.0** and remain open source. The hosted platform is a commercial service built on top.

The same pattern as:

- Nginx (OSS) vs Nginx Plus (commercial)
- Kubernetes (OSS) vs GKE / EKS / AKS (hosted)
- Commerce Gateway (OSS) vs Better Data hosted platform (commercial)
