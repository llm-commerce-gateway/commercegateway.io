title: "Docker"
description: "Run Commerce Gateway in Docker for local or production self-hosted setups."
section: "Self-Hosting"
---

There is **no published `commercegateway/server` image** on Docker Hub as of this writing. Self-host with Node and the npm packages:

```bash
npm install @commercegateway/commerce-gateway @commercegateway/commerce-gateway-mcp
# published CLI still needs gateway.config.json or GATEWAY_CONFIG
npx @commercegateway/commerce-gateway-mcp
```

Programmatic MCP: `createGatewayMCPServer` from `@commercegateway/commerce-gateway/mcp` (see [Quick Start](/docs/getting-started/quick-start)). Publish a first-party image only after a release owner authorizes it.
