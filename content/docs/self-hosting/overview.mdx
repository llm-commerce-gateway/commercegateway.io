## System requirements

- Node.js >= 18
- 512MB RAM minimum
- Linux, macOS, or Windows host

## Installation options

- `npx @commercegateway/commerce-gateway-mcp` (published `1.0.0-rc.2` requires `gateway.config.json`; demo-without-config is unpublished)
- `npm install @commercegateway/commerce-gateway` (programmatic MCP via `/mcp`)
- No first-party Docker image is published yet — see [Docker](/docs/self-hosting/docker)

## Configuration

Use environment variables for ports, auth, provider keys, and backend connectors.

Full reference: [Configuration](/docs/self-hosting/configuration)
