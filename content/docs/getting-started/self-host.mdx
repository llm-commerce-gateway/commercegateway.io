## Minimal self-host setup

Prefer programmatic MCP (`createGatewayMCPServer`) from [Quick start](/docs/getting-started/quick-start). The published MCP CLI (`1.0.0-rc.2`) needs `gateway.config.json` or `GATEWAY_CONFIG`:

```bash
npx @commercegateway/commerce-gateway-mcp
```

A missing config file does **not** start demo backends on the published package.

Connect a storefront: [Shopify Storefront](/docs/getting-started/shopify-storefront), [WooCommerce](/docs/getting-started/woocommerce), or [BigCommerce](/docs/getting-started/bigcommerce).

Use [Self-Hosting Overview](/docs/self-hosting/overview) for deployment options. There is no published first-party Docker image yet ([Docker](/docs/self-hosting/docker)).
