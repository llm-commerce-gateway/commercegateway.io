## Choose your path

Commerce Gateway is open-source. You can run it yourself for free, or use the Better Data hosted platform.

### Self-host (free, open-source)

**Best for:**

- Developers and teams who want full control
- Single-brand or single-tenant deployments
- Evaluating Commerce Gateway before committing to hosted
- Air-gapped or regulated environments

**What you get:**

- Full Commerce Gateway OSS stack (Apache-2.0)
- **gateway-console** — free operator UI for configuration and keys
- All four LLM adapters (Anthropic, OpenAI, Grok, Gemini)
- Shopify, BigCommerce, and WooCommerce connectors
- Optional registry connection for discovery

→ [Self-Host Setup](/docs/getting-started/self-host)  
→ [Quick Start](/docs/getting-started/quick-start)  
→ [Shopify, UCP, and this gateway](/docs/getting-started/shopify-and-ucp)  
→ [gateway-console](/docs/self-hosting/gateway-console)

### Better Data hosted

**Best for:**

- Multi-brand or multi-tenant deployments
- Teams who do not want to manage infrastructure
- Teams who want Better Data to operate the runtime (qualified **pilot**, not self-serve)

**What you get:**

- Managed Commerce Gateway runtime (manually provisioned)
- Isolation, metering, and SLA **only as written in the pilot**
- Same Storefront / Woo / BigCommerce connectors as OSS

→ [Hosted Overview](/docs/hosted/overview)  
→ Contact [hello@betterdata.co](mailto:hello@betterdata.co)

## Decision guide

```
Do you need Better Data to operate the runtime?
  YES → Request a qualified hosted pilot (manually provisioned; not self-serve GA)
  NO  → Self-host

Do you need a published hosted uptime SLA?
  YES → Not a published hosted feature — negotiate only inside a pilot agreement
  NO  → Self-host, or a pilot if you still want Better Data to operate Node

Are you evaluating Commerce Gateway?
  YES → Start self-hosted on the published OSS packages

Do you have infrastructure to manage?
  YES → Self-host
  NO  → Request a hosted pilot; there is no self-serve hosted signup
```

The OSS packages are the same building blocks the hosted runtime uses. Hosted is a separately provisioned pilot — not a GA upgrade path you can flip on.
