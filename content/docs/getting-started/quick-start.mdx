> **Self-hosted or hosted?**  
> This quick start uses **published npm packages** (`1.0.0-rc.2` as of this writing). Hosted Gateway at [gateway.betterdata.co](https://gateway.betterdata.co) is a **managed runtime, not self-serve GA**. See [Hosted Overview](/docs/hosted/overview) and [Self-Host or Hosted?](/docs/getting-started/self-host-or-hosted).
>
> Commerce Gateway is **not** Shopify UCP or Shop MCP. Keep native Shopify AI channels where you use them — [Shopify, UCP, and this gateway](/docs/getting-started/shopify-and-ucp).

There is no `@commerce-gateway/sdk` or `@commerce-gateway/server` package. Install from the `@commercegateway` org:

```bash
npm install @commercegateway/commerce-gateway
# optional storefront connectors
npm install @commercegateway/commerce-gateway-connectors
```

Published `1.0.0-rc.2`: programmatic MCP uses `createGatewayMCPServer` from `@commercegateway/commerce-gateway/mcp`. The MCP CLI (`npx @commercegateway/commerce-gateway-mcp`) on npm still expects a `gateway.config.json` (or `GATEWAY_CONFIG`). A built-in demo config when no file is present is **not** in the published package — do not treat that as an rc.2 capability.

## 1) MCP server with a connector

```ts
import { createGatewayMCPServer } from "@commercegateway/commerce-gateway/mcp";
import { ShopifyConnector } from "@commercegateway/commerce-gateway-connectors/shopify";

const shopify = new ShopifyConnector({
  domain: "my-shop.myshopify.com",
  accessToken: process.env.SHOPIFY_STOREFRONT_TOKEN!,
  apiVersion: "2024-01",
});

const server = createGatewayMCPServer({
  slug: "my-shop",
  brandName: "My Shop",
  endpoint: "https://example.com/mcp",
  protocol: "mcp",
  capabilities: { catalog_search: true, inventory: "real_time" },
  backends: shopify.getBackends(),
});

server.start(); // stdio transport (Claude Desktop / Cursor)
```

This Shopify path is the **Storefront API**, not `https://{shop}/api/ucp/mcp`. Order lookup is not available on Storefront.

Equivalent connectors: [Shopify Storefront](/docs/getting-started/shopify-storefront) · [WooCommerce](/docs/getting-started/woocommerce) · [BigCommerce](/docs/getting-started/bigcommerce)

## 2) MCP CLI (published rc.2)

```bash
# requires gateway.config.json in the working directory, or GATEWAY_CONFIG
npx @commercegateway/commerce-gateway-mcp
```

On **1.0.0-rc.2** a missing config file fails; it does not silently start demo backends. Prefer `createGatewayMCPServer` (section 1) for a first integration. See the [MCP package on npm](https://www.npmjs.com/package/@commercegateway/commerce-gateway-mcp).

## 3) Call an MCP tool

Runtime MCP names (not well-known capability ids such as `product.search`):

```json
{
  "name": "search_products",
  "arguments": {
    "query": "wireless headphones under $100"
  }
}
```

LLM adapters (`AnthropicAdapter`, `OpenAIAdapter`, …) are exported from `@commercegateway/commerce-gateway/adapters` (or `/anthropic`, `/openai`, `/grok`, `/google`).
