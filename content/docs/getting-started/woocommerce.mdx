WooCommerce has no native Shopify-style UCP endpoint. This connector is how a first-party agent talks to a Woo store through Commerce Gateway MCP.

## Install

```bash
npm install @commercegateway/commerce-gateway @commercegateway/commerce-gateway-connectors
```

Current npm prerelease: `1.0.0-rc.2`.

## Configure

REST API consumer key and secret (`wc/v3`):

```ts
import { createGatewayMCPServer } from "@commercegateway/commerce-gateway/mcp";
import { WooCommerceConnector } from "@commercegateway/commerce-gateway-connectors/woocommerce";

const woocommerce = new WooCommerceConnector({
  url: "https://your-store.com/",
  consumerKey: process.env.WOOCOMMERCE_CONSUMER_KEY!,
  consumerSecret: process.env.WOOCOMMERCE_CONSUMER_SECRET!,
  version: "wc/v3",
});

const server = createGatewayMCPServer({
  slug: "your-store",
  brandName: "Your Store",
  endpoint: "https://example.com/mcp",
  protocol: "mcp",
  capabilities: { catalog_search: true },
  backends: woocommerce.getBackends(),
});

server.start();
```

Cart state is session-based in the connector (Woo has no native cart API). Plan persistence separately for production.
