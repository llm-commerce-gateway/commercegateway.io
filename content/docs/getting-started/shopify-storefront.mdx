Use this path for a **first-party** agent you host. Do **not** use it to replace Shopify’s native UCP endpoint (`https://{shop}/api/ucp/mcp`) or Shop MCP on Meta, Google, or Shop. See [Shopify, UCP, and this gateway](/docs/getting-started/shopify-and-ucp).

## Install

```bash
npm install @commercegateway/commerce-gateway @commercegateway/commerce-gateway-connectors
```

Current npm prerelease: `1.0.0-rc.2`.

## Configure

Storefront API access token (Admin API is not used):

```ts
import { createGatewayMCPServer } from "@commercegateway/commerce-gateway/mcp";
import { ShopifyConnector } from "@commercegateway/commerce-gateway-connectors/shopify";

const shopify = new ShopifyConnector({
  domain: "your-store.myshopify.com",
  accessToken: process.env.SHOPIFY_STOREFRONT_TOKEN!,
  apiVersion: "2024-01",
});

const server = createGatewayMCPServer({
  slug: "your-store",
  brandName: "Your Store",
  endpoint: "https://example.com/mcp",
  protocol: "mcp",
  capabilities: { catalog_search: true, inventory: "real_time" },
  backends: shopify.getBackends(),
});

server.start();
```

## What is implemented in source

These operations exist in the Shopify Storefront connector. They are **not** independently validated against a current Shopify API version.

- Catalog search and product detail (`search_products`, `get_product_details`)
- Cart mutations via Shopify Cart API
- `create_order` still uses Storefront `checkoutCreate` (checkout URL handoff). Shopify retired legacy Checkout APIs in 2025. **Do not assume this handoff works** on a supported API version until Track R confirms it.

## What does not

- Shopify UCP / Shop MCP / Catalog MCP
- Order retrieval and order lookup (Storefront cannot; the connector throws if you ask)
- Admin API inventory writes, POs, or back-office ops
